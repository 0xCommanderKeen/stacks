# Followed series and comic runs

Library offers Everything, Books, Comics, and Audio. Comics opens on publication runs, preserving separate identities when names match. Run cards show owned and finished counts within the selected shelf; they do not claim a total publication count. Comics without a series remain available from a separate button. Open a run for its ordered works, displayed issue/annual/special designation, and finished status.

Follow or unfollow from a comic run or a work's series details. Following promotes existing archive defaults to Library and applies the Library default when assigning future members. Explicit Library/Archive choices always win. Unfollowing stops future promotion and leaves previous defaults and personal choices intact. Follow changes use the series revision; promotions also advance affected work revisions.

Grouping preserves explicit personal shelf resolutions. In their absence, combined followed membership promotes the default while retaining any override. Splitting keeps copied personal choices. Undo continues to guard personal facts, and following never changes original files or audio progress.

Home shows the first unfinished owned Library work in each followed series. A finished reading or listening record marks a work finished for this purpose; unfinished records do not. An explicit Archive work remains outside daily next-up choices. Each followed series is a separate sequence, so the same work may be next in more than one sequence. Audio playback remains independent of deliberate reading records.

Media, scope, search, run identity, run and issue offsets, and Home next-page offsets are stored in URLs. Paging, media/scope filtering, run counts, and next selection happen in SQL. Only the selected page's works and finished IDs enter the response. Export version 6 and schema 0006 backups include following state.

Verification covers identical run names, annual/special ordering, follow/unfollow defaults and overrides, future membership, stale changes, run and issue pagination, next-up completion, media/unassigned filtering, backup/restore, and desktop/phone browser navigation. Physical-device and NAS qualification remain release gates.
